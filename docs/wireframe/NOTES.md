# ワイヤーフレームと実装の対応

このフォルダは、ご提供いただいた `hinoyama_wireframe_code.zip` の原本
（`index.html` / `style.css` / `README.original.md`）です。**公開用ファイルではありません。**

実装（リポジトリ直下の `index.html`）は、このワイヤーフレームを
**情報設計・セクション構成・導線の基準**として作成しています。
ワイヤーフレームはデザイン完成版ではないため、見た目（配色・書体・写真の見せ方）のみ
別途ご確認いただいた和の方向で実装しています。

## セクション構成（1対1で対応）

| # | ワイヤーフレーム | 実装（id） | 主なCTA・導線 |
| --- | --- | --- | --- |
| 1 | HERO | `#top` | メニューを見る →（テキストリンク） |
| 2 | CONCEPT こだわりの味 | `#concept` | 詳しく見る → `#shop` |
| 3 | MENU | `#menu` | メニュー一覧を見る → `#menu-list` ／ カード4枚 |
| 4 | SHOP INFORMATION | `#shop` | 項目表＋Google Map |
| 5 | ACCESS 火の山へ行く | `#access` | **Googleマップで経路を見る（Primary CTA）** |
| 6 | NEWS お知らせ | `#news` | Instagramの最新投稿へ → |
| 7 | INSTAGRAM | `#instagram` | Instagramを見る（ボタン） |
| — | FOOTER | `footer` | 店名・住所・サイト内リンク・PROPOSAL DEMO表記 |

ヘッダーもワイヤーフレーム通り、
ロゴ／ナビ（ホーム・メニュー・こだわり・店舗情報・お知らせ）／Instagramアイコン＋
赤い「Googleマップで見る」CTA（`#access` へ）という並びです。

## ワイヤーフレームに無いため実装から外したもの

| 外したもの | 経緯 |
| --- | --- |
| 「はじめて火の山へ」（来店手順01〜05） | 当初ブリーフの指定で追加していたが、ワイヤーフレームに無いため削除 |
| 最終CTAセクション（今日は、火の山へ。） | 同上。来店導線は ACCESS のPrimary CTAに集約 |
| Hero の「Googleマップ」ボタン | ワイヤーフレームのHeroはテキストリンクのみのため、CTAの優先順位を変えないよう削除 |
| スマホ下部の固定CTAバー | ワイヤーフレームに無いため削除。ヘッダーが固定表示のため、スマホでもGoogleマップCTAは常時表示されます |

いずれもコミット `5ea5fe7` に実装が残っているため、復活させる場合はそこから戻せます。

## 内容を差し替えた箇所（事実性のため）

| ワイヤーフレームの記載 | 実装 | 理由 |
| --- | --- | --- |
| メニュー「チャーシューメン」「餃子」 | 4枚目を「その他メニュー（商品・価格 要確認）」に | 提供を公開情報で確認できないため。確認が取れればカードの見出しを差し替えるだけです |
| MENU 見出し「人気のメニュー」 | 「メニュー」 | 人気かどうかを裏づける情報がないため |
| NEWS「2026.09.XX ◯◯のお知らせ」4件 | 2026.09.15 オープンの1件＋「掲載例」3件 | 実際に告知された内容ではないため。確定情報のみ実データにしています |
| HERO「一杯に、想いを込めて。」 | 「豚骨と魚介の旨味を重ねた一杯。姶良市加治木町朝日町の鹿児島ラーメン店です。」 | どの店舗にも使える表現を避け、公式Instagramで確認できる内容にしています。店舗のご意向であればこの1行は差し替え可能です |
| 「詳しく見る」の遷移先 | ワイヤーフレーム通り `#shop`（店舗情報） | 1ページ構成のため下層ページは未作成です |

## 実装側で足している要素（提案デモとして必須のもの）

- ページ最上部・フッターの **PROPOSAL DEMO 表記**
- 未確認情報の「要確認」表示（`.tbc`）
- 検索避け（`<meta name="robots" content="noindex, nofollow">`）
