# 受領したワイヤーフレームと実装の対応

このフォルダは、ご提供いただいた `hinoyama_wireframe_code.zip` の原本
（index.html / style.css / README.original.md）です。**公開用ファイルではありません。**
セクション構成と導線の基準として参照し、実装（リポジトリ直下の `index.html`）へ反映しました。

## 反映したもの

| ワイヤーフレーム | 実装 |
| --- | --- |
| HERO | Hero（店名・一杯の説明・OPEN日・Googleマップ／メニュー導線） |
| CONCEPT こだわりの味 | `#ramen` こだわり／火の山の一杯（ナビ表記は「こだわり」） |
| MENU 4枚のカード＋一覧リンク | `#menu` お品書き（カード4枚＋Instagramへの導線） |

| ACCESS（CTAバンド） | `#access` 火の山へ行く（外観・駐車場・店内写真＋駐車場情報＋経路CTA） |
| NEWS お知らせ | `#news` お知らせ（新設） |
| INSTAGRAM | `#instagram` 最新情報はInstagramで |
| ヘッダーのナビ＋Googleマップの赤いCTA | 同じ構成で実装 |

## 反映しなかったもの（理由つき）

| 項目 | 理由 |
| --- | --- |
| メニューの「チャーシューメン」「餃子」「その他メニュー」 | 公開情報で提供を確認できないため。確認済みの ラーメン／大／特大／トッピング のみ掲載しています。提供が確認できればカードを追加するだけで対応可能です。 |
| お知らせの「2026.09.XX オープンのお知らせ」等の本文 | 実際に告知された内容ではないため。確定している 2026.09.15 のオープンのみ実データとして掲載し、他は「掲載例」と明示しています。 |
| ヒーローの「一杯に、想いを込めて。」 | どの店舗にも使える表現のため、公式Instagramで確認できる「豚骨と魚介の旨味を重ねた一杯」を採用しています。店舗のご意向であればこの1行はいつでも差し替えます。 |
| ナビの「ホーム」 | ロゴがトップへのリンクを兼ねるため省略しています。 |
