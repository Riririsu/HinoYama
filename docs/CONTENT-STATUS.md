```html
<!-- Before -->

```

確定したら `<head>` のJSON-LDにも `openingHoursSpecification` / `telephone` を追記してください
（**未確認のまま登録しない**）。

## 写真について

掲載写真は、ご提供いただいたキービジュアル1枚から切り出して使用しています
（ヒーロー／スープ／具材／暖簾／メニュー4点／カウンター）。
実際の提供写真ではないため、フッターに「写真はイメージ」と明記しています。
店舗撮影後、`assets/img/` の各ファイルを差し替えてください。

| ファイル | 用途 |
| --- | --- |
| `kv-main.webp` | ヒーローの背景（左側の暗部はコピーを載せるために生成） |
| `kv-wide.webp` | 全幅の帯 |
| `d-broth.webp` / `d-chashu.webp` / `noren.webp` | こだわりセクション |
| `dish-main.webp` / `d-chashu.webp` / `d-broth.webp` / `d-egg.webp` | メニューカード |
| `counter.webp` | 最後の一押しの背景 |
| `og.webp` | OGP画像 |
